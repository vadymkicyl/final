Елементи форм в HTML

Форми - інтерактивні елементи для введення даних. Основний тег - <form>.

Найважливіший елемент - <input> з атрибутом type:

Тип Код Приклад Опис
text <input type="text"> Текстове поле
password <input type="password"> Поле для пароля
email <input type="email"> Email з валідацією
number <input type="number"> Числове поле
date <input type="date"> Вибір дати
checkbox <input type="checkbox"> Галочка Вибір опції
radio <input type="radio"> А Б Радіокнопка
file <input type="file"> Завантаження файлу

Інші елементи

Елемент Код Приклад Опис
textarea <textarea> Багаторядкове поле
select <select> Випадаючий список
button <button> Кнопка

Атрибути

Атрибут Опис
name Ім'я для передачі на сервер
value Початкове значення
placeholder Підказка
required Обов'язкове поле
disabled Неактивне поле
min / max Діапазон значень
