📚 HTML для начинающих

Привет! Этот мануал поможет тебе научиться писать HTML - язык для создания веб-страниц.

🏗️ Что такое HTML?

HTML - это как конструктор для веб-страниц. Ты строишь страницу из блоков (тегов), как дом из кирпичиков.

📝 Основная структура

Каждая HTML-страница начинается с этого:

<!DOCTYPE html>
<html>
  <head>
    <title>Моя страница</title>
  </head>
  <body>
    Здесь будет твой контент
  </body>
</html>
💡 Запомни: Теги всегда открываются <tag> и закрываются </tag>

🎨 Таблицы

Таблица - это сетка из строк и колонок. Как Excel, но на веб-странице.

<table>
  <tr> <!-- строка -->
    <td>Ячейка 1</td>
    <td>Ячейка 2</td>
  </tr>
</table>

Результат:

Ячейка 1 Ячейка 2

Основные теги таблицы:

  • <table> - сама таблица
  • <tr> - строка (table row)
  • <td> - ячейка данных (table data)
  • <th> - заголовок ячейки (жирный и по центру)
  • <thead> - заголовок таблицы
  • <tbody> - тело таблицы
  • <tfoot> - подвал таблицы

📝 Формы

Формы - это место, где пользователь может вводить данные: текст, числа, выбирать опции.

Тег <input> - самый важный!

Input - это поле для ввода. Тип поля определяется атрибутом type:

<input type="text"> - текстовое поле
<input type="password"> - поле для пароля
<input type="email"> - для email
<input type="number"> - для чисел
<input type="date"> - выбор даты
<input type="checkbox"> - галочка
<input type="radio"> - радиокнопка
<input type="file"> - загрузка файла

Результат:











Галочка

Радио 1 Радио 2

Другие элементы форм:

  • <textarea> - большое текстовое поле (для нескольких строк)
  • <select> - выпадающий список
  • <button> - кнопка
  • <label> - подпись к элементу

🎯 Радиокнопки (Radio)

Радиокнопки - это когда можно выбрать ТОЛЬКО ОДНУ опцию из группы.

<input type="radio" name="color" value="red"> Красный
<input type="radio" name="color" value="blue"> Синий
<input type="radio" name="color" value="green"> Зеленый

Результат:

Красный
Синий
Зеленый
💡 Важно: Все радиокнопки в группе должны иметь одинаковое name, чтобы работали вместе!

🎨 CSS - стили

CSS - это "одежда" для твоей HTML-страницы. Без CSS страница выглядит скучно.

Как подключить CSS?

<link rel="stylesheet" href="style.css">

Основные CSS свойства:

  • color - цвет текста
  • background-color - цвет фона
  • border - рамка
  • padding - отступ внутри
  • margin - отступ снаружи
  • font-size - размер шрифта

Пример CSS:

.my-class {
  color: red;
  background-color: yellow;
  border: 2px solid black;
  padding: 10px;
}

🔧 Атрибуты

Атрибуты - это дополнительные настройки для тегов. Пишутся так: атрибут="значение"

  • class - имя класса для CSS
  • id - уникальный идентификатор
  • name - имя для форм
  • value - начальное значение
  • placeholder - подсказка в поле
  • required - обязательное поле

📝 Пример полной страницы

<!DOCTYPE html>
<html>
<head>
  <title>Моя первая страница</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая страница.</p>
  <input type="text" placeholder="Введи имя">
</body>
</html>

🎯 Советы для начинающих

  • Всегда закрывай теги! <div>...</div>
  • Используй отступы для читаемости
  • Названия файлов маленькими буквами: index.html, style.css
  • Проверяй код в браузере (F12 - консоль)
  • Практикуйся - это лучший способ научиться!

🚀 Что дальше учить?

  • Больше типов input
  • Сложнее CSS (flexbox, grid)
  • JavaScript для интерактивности
  • Адаптивный дизайн
